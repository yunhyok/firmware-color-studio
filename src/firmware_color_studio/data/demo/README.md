# Color cube sample

`color-cube.dng` is Terry Duell’s original 14-bit PENTAX K-3 Mark III
capture, published as raw.pixls.us sample 4678 on 2021-05-16 under CC0 1.0.
The application decodes the original RAW for its startup preview.
