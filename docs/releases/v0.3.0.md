# Firmware Color Studio v0.3.0

**PENTAX Q7**을 두 번째 카메라로 추가했습니다. 상단의 카메라 메뉴에서 K-3 Mark III와 Q7 중 하나를 고릅니다. K-3 Mark III의 DCP·XMP 출력은 v0.2.2와 바이트 단위로 같습니다.

- **Q7 프로파일 10종:** Natural, Bright, Portrait, Landscape, Vibrant, Radiant, Muted, Bleach Bypass, Reversal Film, Monochrome. Q7 펌웨어 1.01의 색 행렬·감마·YC 계산과 Custom Image 출고값을 그대로 옮겼습니다. Muted와 Bleach Bypass의 조색은 DCP + XMP로 내보냅니다. 내보낸 프로파일의 카메라 이름은 `PENTAX Q7`입니다.
- **카메라 메뉴:** 카메라를 바꾸면 프로파일 목록, 조절 항목, 비교 기준이 그 카메라의 것으로 바뀝니다. Q7에 없는 하이라이트/섀도 대비는 숨깁니다. 고른 카메라는 다음 실행 때도 유지되고, 레시피를 열면 그 레시피의 카메라로 바뀝니다. 차트 JPEG → DCP도 선택한 카메라용으로 만듭니다.
- **CLI:** `fcs recipe`로 출고값 레시피를 쓸 수 있고, `fcs recipe`·`fcs preview`·`fcs chart-fit`에 `--camera pentax-q7`을 줄 수 있습니다.

**Q7에서 확인한 것:** 색 행렬·YC·조색 오프셋 276개 설정과 감마 표 906개(각 4096항목)가 Q7 펌웨어 루틴을 CPU 에뮬레이터로 실행한 결과와 모두 일치합니다. 표는 서로 독립적으로 작성한 두 도구로 추출해 바이트 단위로 같음을 확인했습니다.

**Q7에서 확인하지 못한 것:** Q7로 찍은 사진으로는 검증하지 않았습니다. 카메라 JPEG이나 Lightroom Classic의 결과와 비교한 적이 없고, 전체 밝기 기준(`BaselineExposureOffset`)은 보정 전 값 0이어서 카메라보다 일정하게 밝거나 어두울 수 있습니다. Q7은 행렬과 감마를 9×9×9 3차원 표로 합쳐 보간하는데, Studio는 표가 표본으로 삼은 함수 자체를 쓰므로 표의 격자점 사이에서는 카메라와 조금 다를 수 있습니다. RAW 열기는 K-3 Mark III 파일만 지원하며, Q7을 고른 상태의 미리보기는 K-3 Mark III RAW를 두 카메라의 센서 행렬로 환산한 근사입니다. [Q7 지원 범위와 한계](https://github.com/yunhyok/firmware-color-studio/blob/v0.3.0/docs/q7.md)

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다. 코드 서명이 없는 설치 파일입니다.
