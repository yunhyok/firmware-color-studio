# Firmware Color Studio v0.3.0

**PENTAX Q7**을 두 번째 카메라로 추가했습니다. 상단의 카메라 메뉴에서 K-3 Mark III와 Q7 중 하나를 고릅니다. K-3 Mark III의 펌웨어 모드 DCP·XMP 출력은 v0.2.2와 바이트 단위로 같습니다.

- **Q7 프로파일 10종:** Natural, Bright, Portrait, Landscape, Vibrant, Radiant, Muted, Bleach Bypass, Reversal Film, Monochrome. Q7 펌웨어 1.01의 색 행렬·감마·YC 계산, 카메라가 보간하는 9×9×9 3차원 표와 Custom Image 출고값을 그대로 옮겼습니다. Muted와 Bleach Bypass의 조색은 DCP + XMP로 내보냅니다. 내보낸 프로파일의 카메라 이름은 `PENTAX Q7`입니다.
- **카메라 메뉴:** 카메라를 바꾸면 프로파일 목록, 조절 항목, 비교 기준이 그 카메라의 것으로 바뀝니다. Q7에 없는 하이라이트/섀도 대비는 숨깁니다. 고른 카메라는 다음 실행 때도 유지되고, 레시피를 열면 그 레시피의 카메라로 바뀝니다. 차트 JPEG → DCP도 선택한 카메라용으로 만듭니다.
- **Q7 DNG 열기:** Q7 DNG를 열면 카메라가 Q7로 바뀝니다. 촬영 설정 가져오기와 DNG 보정 행렬 가져오기도 Q7 파일에서 동작합니다.
- **차트 JPEG → DCP의 밝기 기준:** 기증 JPEG을 찍을 때의 노출이 프로파일에 섞이지 않도록, 회색 패치의 밝기 수준을 선택한 카메라의 Natural에 맞춥니다. 톤 곡선의 모양은 기증 JPEG의 것을 그대로 씁니다. 같은 차트를 찍은 Pentax RAW에 적용했을 때 v0.2.2의 프로파일은 0.6~1.0 EV 밝았습니다. 이 변경으로 차트 DCP의 수치는 v0.2.2와 달라집니다. [8대의 카메라로 찍은 검증](https://github.com/yunhyok/firmware-color-studio/blob/v0.3.0/docs/chart-profiles.md#same-scene)
- **CLI:** `fcs recipe`로 출고값 레시피를 쓸 수 있고, `fcs recipe`·`fcs preview`·`fcs chart-fit`에 `--camera pentax-q7`을 줄 수 있습니다. `fcs preview`는 `--camera`를 생략하면 RAW를 찍은 카메라를 씁니다.

**Q7에서 확인한 것:** 색 행렬·YC·조색 오프셋 276개 설정, 감마 표 1,636개(각 4096항목), 기본 감마 표와 3차원 표의 729개 격자점(794개 설정)이 Q7 펌웨어 루틴을 CPU 에뮬레이터로 실행한 결과와 모두 일치합니다. 표는 서로 독립적으로 작성한 두 도구로 추출해 바이트 단위로 같음을 확인했습니다. ColorChecker를 찍은 Q7 DNG 한 장(펌웨어 1.01, ISO 100, Landscape 출고값)에서 Landscape 프로파일과 DNG에 들어 있는 카메라 JPEG의 24패치 평균 색차는 ΔE76 1.5(유채색 1.6, 회색 1.2, 최대 7.6)입니다. 전체 밝기 기준(`BaselineExposureOffset` +0.5 EV)과 3차원 표의 보간 방식(사면체)은 이 사진으로 정했습니다. 같은 차트를 찍은 K-3 Mark III DNG(펌웨어 2.12)에서는 2.3입니다.

**Q7에서 확인하지 못한 것:** 사진 비교는 한 대, 한 감도, 한 Custom Image에 한합니다. Lightroom Classic으로 Q7 DNG를 현상해 비교하지는 않았습니다. 다른 감도나 하이라이트·섀도 보정에서 카메라가 쓰는 이득 값은 확인하지 않았습니다. Muted의 조색 색이 Q7 메이커노트의 어디에 기록되는지 몰라 촬영 설정 가져오기에서 빠집니다. [Q7 지원 범위와 한계](https://github.com/yunhyok/firmware-color-studio/blob/v0.3.0/docs/q7.md)

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다. 코드 서명이 없는 설치 파일입니다.
