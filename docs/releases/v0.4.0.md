# Firmware Color Studio v0.4.0

다른 카메라의 색감을 프로그램에 내장했고, 카메라가 Custom Image별로 직접 현상한 JPEG 25장으로 두 카메라 팩을 다시 검증해 Q7 팩을 고쳤습니다. K-3 Mark III의 펌웨어 모드 DCP·XMP 출력은 v0.2.2와 바이트 단위로 같습니다.

- **다른 카메라 색감(내장):** 상단의 **다른 카메라 색감**에서 Kodak C875, Sony DSC-P200, Sony DSC-TX66, Sony DSC-T100, Konica Minolta DiMAGE X1, Samsung EX1 가운데 하나를 고르면 차트 JPEG 없이 선택한 카메라(K-3 Mark III 또는 Q7)용 DCP를 만듭니다. 각 카메라가 같은 ColorChecker를 찍은 JPEG 한 장에서 잰 24패치 값이며 제조사의 프로파일이 아닙니다. CLI는 `fcs look list`, `fcs look "Sony DSC-P200" out.dcp --camera pentax-q7`입니다. [내장 색감](https://github.com/yunhyok/firmware-color-studio/blob/v0.4.0/docs/chart-profiles.md#built-in-looks)
- **Q7 하이라이트 채도 억제:** Q7은 밝기 200(255 기준)부터 흰색까지 채도를 직선으로 줄입니다. v0.3.0에는 이 단계가 없어 밝은 노랑이 카메라보다 진했습니다(노랑 패치 ΔE 7~14 → 2~4). 시작 밝기 200은 펌웨어의 값이고, 흰색에서 0이 되는 기울기는 카메라 JPEG에서 읽었습니다.
- **Q7 조색 순서:** Muted·Bleach Bypass의 조색을 채도 억제 앞에 더합니다. 흰색에 남는 색조가 카메라와 같아집니다.
- **Q7 촬영 설정:** Muted의 조색 색도 메이커노트에서 가져옵니다(Bleach Bypass와 같은 태그).
- **고친 오류:** Q7 RAW를 연 상태에서 차트 대화상자의 RAW 미리보기가 K-3 Mark III RAW로 취급해 색을 환산하던 문제(v0.3.0).

**확인한 것:** Q7 DNG 한 장을 카메라에서 Custom Image 10종으로 현상한 JPEG과, 각 JPEG에 기록된 설정으로 만든 프로파일의 24패치 평균 색차는 ΔE76 0.97~1.43(최대 3.70)입니다. 색상·키·채도를 바꾼 컷과 조색(Bleach Bypass Green)도 포함합니다. K-3 Mark III는 13종(SATOBI, Gold, 여섯 설정을 모두 바꾼 Portrait 포함)에서 0.20~3.19입니다. Q7의 펌웨어 루틴 대조(색 276, 감마 1,636, 표 794 설정)는 그대로 모두 일치합니다. [측정값](https://github.com/yunhyok/firmware-color-studio/blob/v0.4.0/docs/chart-session-validation.json)

**확인하지 못한 것:** 한 장면, ISO 100입니다. Lightroom Classic으로는 현상해 보지 않았습니다. K-3 Mark III는 밝고 진한 노랑·주황에서 카메라가 모델보다 진하고 어둡게 나오는 차이(주황노랑 패치 ΔE 3~12)가 남아 있고 고치지 않았습니다. Q7 Reversal Film은 카메라가 화이트밸런스를 따로 잡아 현상하므로 프로파일만으로는 그 차이가 남습니다. 내장 색감은 사진 한 장씩에서 잰 값이어서 노출과 조명이 다른 장면에서는 노출을 따로 맞춰야 합니다.

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다. 코드 서명이 없는 설치 파일입니다.
