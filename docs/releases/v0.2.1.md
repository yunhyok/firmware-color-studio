# Firmware Color Studio v0.2.1

**차트 JPEG → DCP**에서 JPEG를 열면 ColorChecker Classic 24의 위치와 방향을 찾고 색감을 자동으로 추정합니다. 화면의 24개 번호와 RAW 미리보기를 확인한 뒤 DCP를 저장하세요. 촬영 기종명이 기본 이름으로 들어갑니다.

자동 인식에 실패했을 때만 차트의 바깥 네 모서리를 지정해 달라는 안내가 나타납니다. 네 번째 모서리를 누르면 색감 추정까지 자동으로 진행됩니다. CLI의 `fcs chart-fit`도 좌표 없이 동작하며, 기존 `--corners` 명령을 그대로 사용할 수 있습니다. [사용 방법과 검증](https://github.com/yunhyok/firmware-color-studio/blob/v0.2.1/docs/chart-profiles.md)
