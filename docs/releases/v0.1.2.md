# Firmware Color Studio v0.1.2

Gold·조색의 색상 경계 처리와 PEF 미리보기를 개선했습니다. 사진 fitting 없이 펌웨어의 정수 표와 Adobe 처리 순서를 근거로 수정했습니다.

- Gold 감마 입력 0에서 사라지던 청색 첫 항목을 보존합니다. 원본 ARM 코드로 sRGB 96/1023, Adobe RGB 120/1023을 다시 확인했습니다.
- Enhanced 프로파일은 펌웨어 CC0 행렬을 짝이 되는 DCP에서 먼저 적용합니다. LUT가 색상 클리핑 경계를 가로질러 보간하던 오차를 줄이고 Adobe의 행렬 반올림·D50 정규화를 반영합니다.
- 198개 레시피, 18,666,801개 합성 RGB 입력을 비교했습니다. 감마 오류를 먼저 바로잡은 기존 방식 대비 기본 Gold/sRGB의 최대 채널 오차는 110.379에서 4.015/255로 감소했습니다. 이 유한 표본에서 남은 전체 최대 오차는 29.481/255이며, 모든 색상·설정에 대한 상한은 아닙니다.
- PEF는 검증한 Adobe 변환 경로의 −0.3 EV와 white-level 상한 16315를 반영합니다. 동일 촬영 PEF와 변환 DNG의 CFA가 완전히 같음을 확인했으며, 기존 펌웨어 기준 값도 메타데이터에 남깁니다.
- 테스트에 사용한 Terry Duell의 CC0 컬러 큐브 DNG를 포함했습니다. 인자 없이 실행하면 자동으로 열리며, 파일을 지정하면 해당 RAW가 우선합니다.

기존 Gold·조색 ZIP은 이 버전에서 다시 내보내고 DCP와 XMP를 함께 가져오십시오. v2 base DCP는 짝이 되는 XMP와 함께 사용해야 합니다. 일반 DCP 16개의 기존 수치 데이터와 영문·한글 병기는 유지합니다.
