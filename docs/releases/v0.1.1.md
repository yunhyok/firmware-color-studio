# Firmware Color Studio 0.1.1

0.1.0의 오류 수정판입니다. 색 계산, 16개 기본 DCP의 수치 데이터와 레시피 형식(`pack_version 2.20-1`)은 바뀌지 않았습니다. 0.1.0에서 만든 DCP와 레시피를 그대로 쓸 수 있습니다.

- **RAW 열기 실패 뒤 미리보기 멈춤 수정:** 지원하지 않는 파일을 열면 이전 사진이 화면에 남은 채 슬라이더에 반응하지 않았습니다. 이제 새 파일을 다 읽을 때까지 현재 사진을 유지하고, 실패하면 그대로 계속 사용합니다.
- **출력 형식 복귀:** Gold나 조색 때문에 DCP + XMP (ZIP)으로 바뀐 출력 형식이 일반 모드로 돌아와도 ZIP으로 남았습니다. 이제 DCP로 복귀합니다. 직접 고른 ZIP 형식은 유지됩니다.
- **ZIP 묶음 파일 이름 충돌 수정:** 모든 묶음이 `base.dcp`, `profile.xmp`, `recipe.json`을 썼기 때문에 두 묶음을 같은 폴더에 풀면 먼저 넣은 프로파일을 덮어썼습니다. 이제 XMP와 레시피는 모드와 프로파일 UUID, base DCP는 팩 버전과 보정 행렬 식별값으로 이름을 정합니다. 프로파일 내용과 Lightroom에 표시되는 이름은 그대로입니다.
- **화면 배율 100% 초과 시 미리보기 흐림 수정:** Windows 배율 125–200%에서 미리보기를 논리 픽셀 크기로 만든 뒤 다시 확대했습니다. 이제 실제 화면 픽셀에 맞춥니다.
- **미리보기 안내문:** DCP + XMP 미리보기 중 언어를 바꾸면 DCP 안내문으로 바뀌던 표시를 고쳤습니다.
- 버전 표기, 릴리즈 노트, 태그가 어긋나면 빌드가 실패하도록 검사를 추가했습니다.

설치 파일은 `FirmwareColorStudio-0.1.1-windows-x64-setup.exe`입니다. 0.1.0 위에 그대로 설치하면 됩니다. Python 설치는 필요 없습니다. 코드 서명이 없는 설치 파일입니다.

**검증 범위:** 위 수정은 자동 테스트와 화면 없는(offscreen) 실행으로 확인했습니다. Lightroom Classic 실기 검증은 0.1.0의 21건 그대로이며, 바뀐 ZIP 파일 이름으로 Lightroom 가져오기를 다시 실행하지는 않았습니다. XMP와 base DCP의 내용은 0.1.0과 바이트 단위로 같습니다. [검증 기록](https://github.com/yunhyok/firmware-color-studio/blob/v0.1.1/docs/validation.md)

**한계:** 0.1.0과 같습니다. 카메라 JPEG와 픽셀 단위로 같지 않습니다. Gold/조색 LUT의 고채도·클리핑 경계에서 큰 국소 오차가 남습니다. PEF 미리보기는 Lightroom과의 차이가 DNG보다 크며 원인은 확인되지 않았습니다. Pixel Shift/HDR/Monochrome 본체 및 변환 DNG 미리보기는 지원하지 않습니다.

원본 펌웨어와 검증 사진은 배포하지 않습니다. [연구 출처](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/tree/aa885bcdaee874d9b9bb18663dd62ed10263eda2) · [라이선스·해당 라이브러리 소스 다운로드](https://github.com/yunhyok/firmware-color-studio/blob/v0.1.1/THIRD_PARTY_NOTICES.md)

English: Bug-fix release; color math, packaged DCP data and the recipe format are unchanged. A rejected RAW no longer freezes the current preview; the export format returns to DCP after leaving Gold or toning; files inside each DCP + XMP ZIP now have unique names so bundles unpacked together do not overwrite each other; previews are sharp on scaled displays; the preview note follows the output format after a language change. The installer is unsigned. Lightroom was not re-run for this release; the exported XMP and base DCP bytes are identical to 0.1.0.
