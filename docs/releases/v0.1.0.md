# Firmware Color Studio 0.1.0

첫 Windows 공개 버전입니다. PENTAX K-3 Mark III 펌웨어 2.20의 공개 연구를 바탕으로 DCP를 생성하고 RAW 색상을 비교합니다. 사진 기반 fitting은 사용하지 않습니다.

- 16개 기본 프로파일 및 카메라 색상 조절값을 반영한 커스텀 DCP
- Gold와 조색 효과의 DCP + XMP ZIP 출력
- PEF/DNG ½ 해상도 미리보기, 비교 기준 선택, 모니터 ICC 적용
- 채도·색상·밝기·대비·하이라이트/섀도 조정, 촬영 설정 가져오기, JSON 레시피 저장
- 앱과 Lightroom 출력 이름에 영문·한글 병기
- 카메라별 데이터 팩과 버전 검증 구조

설치 파일은 `FirmwareColorStudio-0.1.0-windows-x64-setup.exe`입니다. Python 설치는 필요 없습니다. 관리자 권한 없이 사용자 폴더에 설치합니다. 코드 서명이 없는 설치 파일입니다.

Lightroom Classic 16.0에서 기본·사용자 DCP와 Gold·조색 XMP를 포함한 **21건의 실제 TIFF 출력**을 확인했습니다. [검증 기록 및 수치](https://github.com/yunhyok/firmware-color-studio/blob/v0.1.0/docs/validation.md)

**한계:** 카메라 JPEG와 픽셀 단위로 같지 않습니다. Gold/조색 LUT의 고채도·클리핑 경계에서 큰 국소 오차가 남습니다. 명목 상태 외의 미해결 내부 플래그, Pixel Shift/HDR/Monochrome 본체 및 변환 DNG 미리보기는 지원하지 않습니다. 샤프니스·노이즈 감소·렌즈 보정은 포함하지 않습니다.

원본 펌웨어와 검증 사진은 배포하지 않습니다. [연구 출처](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/tree/aa885bcdaee874d9b9bb18663dd62ed10263eda2) · [라이선스·해당 라이브러리 소스 다운로드](https://github.com/yunhyok/firmware-color-studio/blob/v0.1.0/THIRD_PARTY_NOTICES.md)
