# Firmware Color Studio v0.4.1

프로그램 안에 사용 설명서를 넣었습니다. 색 계산과 내보내는 DCP·XMP는 v0.4.0과 같습니다.

- **도움말 메뉴와 사용 설명서(F1):** 메뉴에 **도움말**이 생겼고, **사용 설명서**(F1)를 누르면 프로그램 자체 창에서 설명서가 열립니다. 웹 브라우저나 인터넷이 필요 없습니다. 창 위쪽의 **웹 브라우저로 열기**로 같은 문서를 브라우저에서 볼 수도 있습니다.
- **설명서 내용:** 화면 구성(번호를 붙인 실제 화면), RAW 열기부터 내보내기까지의 순서, 조절 항목과 모드별 차이, 출력 형식과 레시피, 내장 색감과 차트 JPEG → DCP, **Lightroom Classic·Lightroom·Camera Raw에 DCP와 ZIP을 추가하는 방법**과 수동 설치 폴더, 프로파일이 보이지 않을 때의 확인 사항, 메뉴와 단축키, 명령줄, 문제 해결을 담았습니다. 펌웨어에서 색을 복원한 방법은 개념도와 함께 간단히 적었습니다.
- **메뉴 변경:** **상세 정보**가 파일 메뉴에서 도움말 메뉴로 옮겨졌고, F1은 상세 정보 대신 사용 설명서를 엽니다.

**확인한 것:** 설명서가 가리키는 그림과 문서 안 링크가 모두 있는지, 도움말 메뉴와 F1이 프로그램 안 창에 설명서와 그림을 띄우는지를 테스트에 넣었습니다. 설명서의 화면 그림은 이 버전의 프로그램에서 직접 찍었습니다([그림을 만드는 스크립트](https://github.com/yunhyok/firmware-color-studio/blob/v0.4.1/tools/build_help_images.py)).

**확인하지 못한 것:** 설명서는 한국어로만 제공합니다. Lightroom의 가져오기 순서는 Adobe의 안내를 따라 적었고, 이번 버전에서 Lightroom을 실행해 다시 확인하지는 않았습니다. Lightroom 그림은 실제 화면이 아니라 순서를 나타낸 개념도입니다. 설치 파일에 들어간 설명서는 설치해서 열어 보지 않았습니다.

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다. 코드 서명이 없는 설치 파일입니다.
