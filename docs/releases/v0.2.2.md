# Firmware Color Studio v0.2.2

**차트 JPEG → DCP** 창의 오류와 사용성을 고쳤습니다. 색감 추정 계산, 펌웨어 모드의 DCP·XMP 출력은 v0.2.1과 같습니다.

- **Enter 키 오동작 수정:** 프로파일 이름 칸에서 Enter를 누르면 **다른 JPEG 열기**가 실행됐습니다. 이제 DCP 저장으로 이어집니다.
- **모서리 순서 자동 판정:** 자동 인식에 실패해 바깥 네 모서리를 직접 누를 때, 순서가 틀리면 영어 오류와 함께 처음부터 다시 지정해야 했습니다. 이제 어떤 순서로 눌러도 인쇄된 색 배열로 방향을 찾습니다. 흑백처럼 색으로 방향을 알 수 없는 JPEG에서만 안내 그림의 ①→④ 순서를 사용합니다. 글자로 그려 줄이 어긋나던 안내도는 번호가 붙은 차트 그림으로 바꿨습니다.
- **이름을 고쳐도 결과 유지:** 이름을 한 글자 고칠 때마다 추정 결과가 지워지고 RAW 미리보기에서 차트 탭으로 돌아갔습니다. 이제 결과와 보던 탭을 유지하고, 저장할 때의 이름을 DCP에 기록합니다. 차트 제조 시기를 바꾸면 보던 탭에서 바로 갱신합니다.
- **결과 읽기 쉽게:** 색 비교표를 키우고 평균 ΔE76에 "보정 전 → 보정 후"를 표시합니다. 보정표가 오차를 줄이지 못해 기준 프로파일을 저장하는 경우와 차트가 여러 개 보이는 경우를 따로 알리고, 추정 실패 사유를 한국어로 표시합니다.
- **끌어 놓기:** JPEG를 메인 창에 끌어 놓으면 차트 창을 드롭 처리 도중에 열었기 때문에, 창을 닫을 때까지 끌어 온 탐색기 창이 응답하지 않을 수 있었습니다. 이제 드롭이 끝난 뒤에 엽니다. 차트 창에도 다른 JPEG를 끌어 놓을 수 있습니다.
- 메뉴 제목을 번역하고, 시작할 때 자동으로 열리는 사진에 "데모 사진"을 표시합니다. 차트 창을 연 뒤에 RAW 로딩이 끝나도 RAW 미리보기를 쓸 수 있습니다.
- `fcs chart-fit --outer-corners`도 모서리 순서를 색 배열로 맞춥니다.

**검증 범위:** 자동 테스트와 화면 없는(offscreen) 실행, 화면 캡처로 확인했습니다. 모서리 방향 판정은 원근·회전·테두리 폭·색감·클릭 순서를 무작위로 바꾼 합성 차트 240건에서 모두 올바른 패치를 읽었습니다. 실물 차트 사진과 Lightroom Classic으로는 다시 확인하지 않았습니다. 같은 JPEG·좌표·이름으로 만든 차트 DCP와 `fcs verify`의 17개 모드 해시는 v0.2.1과 바이트 단위로 같습니다. [사용 방법과 검증](https://github.com/yunhyok/firmware-color-studio/blob/v0.2.2/docs/chart-profiles.md)

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다. 코드 서명이 없는 설치 파일입니다.
