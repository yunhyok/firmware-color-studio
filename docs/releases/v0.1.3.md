# Firmware Color Studio v0.1.3

K-3 Mark III의 Gold(골드)와 조색 등 DCP + XMP 프로파일에서 색상 경계를 지나는 32³ LUT의 보간을 개선했습니다. 펌웨어 수식으로 계산한 색과 Lightroom의 사면체 보간 결과를 비교했습니다.

- 기존 합성 RGB 18,666,801개에서 198개 레시피 모두 평균·95·99백분위 오차가 감소했습니다. 관측 최대 오차는 29.481에서 27.990/255로 줄었습니다. 최대 오차가 커진 레시피도 10개 있습니다.
- 별도 표본의 최종 sRGB 클리핑 경계 83,684점에서 레시피별 99백분위 중 가장 큰 값은 14.774에서 8.496/255로, 최대 오차는 24.059에서 19.720/255로 감소했습니다.
- 기본 Gold의 최대 오차는 카메라 sRGB에서 4.015 → 3.174/255, Adobe RGB에서 18.923 → 13.093/255였습니다. 회색 대각선과 LUT 모서리의 16비트 값도 대조했습니다.
- Lightroom Classic 16.0에서 컬러 큐브 DNG에 Gold, Muted, Bleach Bypass를 적용해 세 TIFF의 프로파일과 RGB 테이블 식별자를 확인했습니다. [실제 내보내기 검증](https://github.com/yunhyok/firmware-color-studio/blob/v0.1.3/docs/lut-boundary-lightroom.json)

저장한 레시피를 열어 ZIP을 다시 내보낸 뒤 Lightroom의 프로파일 가져오기로 불러오면 새 LUT가 적용됩니다. 이전 버전과 함께 사용하려면 새 프로파일에 구별되는 이름을 붙이십시오.
