# Firmware Color Studio v0.2.0

다른 카메라로 찍은 ColorChecker Classic 24패치 JPEG 한 장에서 색감을 추정해 PENTAX K-3 Mark III용 Lightroom DCP를 만들 수 있습니다.

1. **차트 JPEG → DCP**를 열고 차트 제조 시기를 선택합니다. X-Rite Classic과 Passport의 Classic 24패치 면을 지원합니다.
2. 짙은 피부색, 청록색, 검정, 흰색의 네 패치 가운데를 차례로 클릭한 뒤 **색감 추정**을 누릅니다. 24개 패치의 JPEG 색과 추정 색, 현재 열린 Pentax RAW 미리보기를 확인할 수 있습니다.
3. **DCP 저장**을 누르고 Lightroom의 프로파일 브라우저에서 가져옵니다. EXIF에 기록된 촬영 기종명이 기본 이름이며, 저장 전에 수정할 수 있습니다.

차트 사진 속 화이트밸런스, 조명과 JPEG 편집도 추정 결과에 영향을 줍니다. 기존 펌웨어 모드는 종전의 공식과 표를 사용합니다. [색감 추정 방식과 실물 차트 검증](https://github.com/yunhyok/firmware-color-studio/blob/v0.2.0/docs/chart-profiles.md)

Windows x64 설치 파일의 체크섬은 같은 릴리스의 `SHA256SUMS.txt`에 있습니다.
