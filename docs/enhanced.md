# Enhanced profiles

Firmware Color Studio exports an XMP profile, its matching base DCP and the source recipe in one ZIP. Use **Import Profiles and Presets** in Adobe Camera Raw. For manual installation, place the DCP in the CameraRaw/CameraProfiles directory and the XMP in CameraRaw/Settings. The XMP matches the base DCP by its embedded name, so keep both files when moving the profile between computers. [Adobe Camera Raw installation instructions](https://helpx.adobe.com/camera-raw/desktop/edit-and-enhance-images/tone-and-color/adjust-color-rendering-camera-camera.html)

The base DCP uses the common sensor ForwardMatrix, a linear tone curve, an identity LookTable and the +0.5 EV profile offset. The XMP LUT carries the Custom Image matrix, gamma, YC conversion and chroma suppression. It includes the selected toning offset or Gold's three hardware gamma curves when the recipe calls for them. The recipe's optional ColorMatrix1/2 pair goes in the base DCP for camera-specific white balance calibration. [Published firmware profile derivation](https://github.com/yunhyok/pentax-k3iii-firmware-analysis/blob/aa885bcdaee874d9b9bb18663dd62ed10263eda2/analysis/firmware-dcp.html)

The 32³ RGB table uses ProPhoto RGB primaries with the sRGB transfer function, matching the size limit documented for Adobe's enhanced profile authoring workflow. Each output channel is rounded to unsigned 16-bit code values. The XMP uses the Adobe DNG SDK RGB table stream, zlib container, XMP base-85 encoding and MD5 table identifier. The app's renderer uses the same quantized samples and tetrahedral interpolation. The 16-bit quantization step is 1/65535 in encoded table space. [Adobe Profiles SDK and DNG SDK](https://www.adobe.com/support/downloads/dng/dng_sdk.html)

## Preview and validation

The offline renderer applies BaselineExposure and the base DCP offset once. A positive total scales the ProPhoto ramp before the LUT. A negative total shapes the base tone curve before the XMP LUT, following the DNG reference exposure operation and Adobe's documented late placement of RGB LUTs. The preview models this processing on white-balanced camera RGB and displays SDR sRGB. [Adobe Profiles SDK and DNG SDK](https://www.adobe.com/support/downloads/dng/dng_sdk.html)

The LUT approximates the firmware transform between sampled grid points. Deep shadows, highlight clipping and highly saturated colors can produce larger differences. Over seeded sensor values restricted to 0.02…0.6, filtered to ProPhoto components between 0.05 and 0.95 at zero total exposure, the Natural, green-toned Bleach Bypass and Gold tests in both color spaces show mean absolute error under 0.65 and 95th-percentile absolute error under 1.4 in 8-bit sRGB code values. These statistics do not bound the maximum: a documented Gold/AdobeRGB sample has a blue-channel difference of about 59/255. See [validation.md](validation.md#fidelity-boundary) for its exact input. Adobe Camera Raw and Lightroom also apply their own demosaic, process version and edits. [Enhanced profile regression cases](../tests/test_enhanced.py)
